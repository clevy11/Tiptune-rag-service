# TipTune support knowledge base

## What TipTune is

TipTune is a real-time song-request platform for DJs, artists, and live events
in Kigali and beyond. It helps attendees request and vote on the next track.

Source: https://tiptune.space/ (reviewed 2026-10-07)

## Starting an event

An organizer can create a free event, generate a unique event link and QR code,
and share them with attendees. No credit card is required to create an event.

Source: https://tiptune.space/ (reviewed 2026-10-07)

## Joining and requesting songs

Attendees join through the event link or QR code shared by the organizer. They
can make song requests and vote on requests at the live event.

Source: https://tiptune.space/ (reviewed 2026-10-07)

## Event dashboard

Each event has a real-time dashboard for managing song requests and tracking
activity during the event.

Source: https://tiptune.space/ (reviewed 2026-10-07)

## Supported event types

TipTune is intended for different kinds of events, including club nights,
rooftop parties, corporate events, and outdoor festivals.

Source: https://tiptune.space/ (reviewed 2026-10-07)
